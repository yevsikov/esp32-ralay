# ESP32 Relay - Learning Project

This is a small educational project for the [Embedded Development course](https://beetroot.academy/courses/online/kurs-embedded-development)

## Circuit Diagram

```
GPIO5
    |
    +-----> IN relay

GPIO18
    |
    +<----- NO

3.3V
    |
    +-----> COM

External 5V
    |
    +-----> VCC

GND
    |
    +-----> GND
```
